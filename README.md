# 命盘草图工具（ziwei-sketch）

紫微斗数笔记配图的单文件 SVG 草图工具。零安装、零依赖，打开即用。

## 这是什么

画紫微斗数命盘草图的工具：自动生成 4×4 命盘（12 宫 + 中空），填天干、宫位名、星曜，画四化飞星连线（禄/权/科/忌），导出高清 PNG 图片插入笔记。

## 怎么用

- 在线使用：访问 [https://falicezhang-source.github.io/ziwei-sketch/](https://falicezhang-source.github.io/ziwei-sketch/)，浏览器打开即用。
- 本地使用：下载 index.html，双击打开即可，无需安装任何东西。
- 输入支持：鼠标、触控板、触控笔（Apple Pencil）、手指。

## 功能

- 4×4 命盘 + 12 地支 + 中宫中空
- 天干下拉选择，输入一宫自动联动填充其余 11 宫
- 宫位名、星曜名、四化、来因宫标注
- 四色画线（禄绿 / 权紫 / 科蓝 / 忌红）：对宫直线、虚线曲线、宫外直线
- 撤销 / 删除选中线 / 一键清空
- 导出图片 / 下载图片
- 自动保存与恢复（进度存于网址片段，本地留存）

## 数据与隐私

所有数据只保存在使用者自己的浏览器本地，不上传、不联网传输。
